საგამოცდო სისტემის გაშვების ინსტრუქცია Google-ში (Google Apps Script)
================================================================================

ეს გზა გაძლევთ 100%-იან გარანტიას, რომ სისტემა იმუშავებს მუდმივად (3-4 თვე და მეტიც),
ყოველგვარი გათიშვების გარეშე, და ყველა კანდიდატის ქულა პირდაპირ თქვენს Google ცხრილში ჩაიწერება.

ნაბიჯ-ნაბიჯ ინსტრუქცია (სულ 2 წუთი):

1. შედით საიტზე: https://sheets.google.com და შექმენით ახალი ცარიელი ცხრილი (დაარქვით მაგალითად: "საგამოცდო შედეგები").
2. ზედა მენიუში დააჭირეთ: Extensions (გაფართოებები) -> Apps Script.
3. ფაილში "Code.gs" წაშალეთ რაც წერია და ჩასვით "Code.gs" ფაილის შიგთავსი.
4. მარცხენა მენიუში "Files"-ის გასწვრივ დააჭირეთ პლიუსს (+) -> აირჩიეთ "HTML" -> დაარქვით ზუსტად: Index
5. გახსენით ფაილი "Index.html" (მდებარეობს საქაღალდეში: Z:\ტესტირება\google_apps_script\Index.html), 
   მონიშნეთ მთლიანად (Ctrl+A), დააკოპირეთ (Ctrl+C) და ჩასვით იქ შექმნილ Index ფაილში (Ctrl+V).
6. ზედა მარჯვენა კუთხეში დააჭირეთ ლურჯ ღილაკს: "Deploy" (განთავსება) -> "New deployment" (ახალი განთავსება).
7. მარცხენა კუთხეში დააჭირეთ გადაცემათა კოლოფის ხატულას (Gear icon) -> აირჩიეთ "Web app".
   - Description (აღწერა): საგამოცდო სისტემა
   - Execute as: Me (თქვენი მეილი)
   - Who has access (ვის აქვს წვდომა): Anyone (ყველას)
8. დააჭირეთ "Deploy" -> Google მოგთხოვთ ნებართვას (Review permissions -> აირჩიეთ თქვენი მეილი -> Advanced / დამატებითი -> Go to Untitled project / გადასვლა -> Allow / დაშვება).
9. მიიღებთ მზა ვებ-მისამართს (Web App URL, მაგ: https://script.google.com/macros/s/.../exec).

ეს არის თქვენი მუდმივი საგამოცდო ბმული, რომელიც შეგიძლიათ გაუგზავნოთ ნებისმიერ კანდიდატს!
